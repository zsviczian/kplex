# Refactor test seams — C01

`npm test` runs `tests/indexing.test.mjs` through `scripts/run-indexing-tests.mjs`. The suite transpiles the explicit TypeScript list in `compile()` into a temporary CommonJS tree and executes selected production modules with Obsidian test doubles. It also reads UI and plugin source as text. A source-text assertion proves only that a fragment remains in a named file; it does not prove the behavior. Retain these checks until the corresponding behavioral check exercises the moved implementation.

## Behavior comparison now available

- `tests/support/canonicalGraph.mjs` normalizes published pages, relations, all original evidence declarations, relationship explanations and resolver decisions. It omits generated declaration IDs and file modification times, while retaining provenance, direction, suppressed evidence and duplicate declarations. `canonicalPair()` compares a specific incremental relation and its evidence against a clean rebuild.
- `tests/fixtures/excalibrain-indexing/graph-baseline.json` captures the initial fixture state before runtime edits: full graph, representative Markdown/folder/tag neighborhoods, an ordinary `buildScene()` projection and search ordering. Treat changes to this file as reviewed behavior changes; explain each changed field. Regenerate only from an intentionally reviewed production result, never by blindly accepting a diff.
- The later tag-tree patch test compares both affected pairs with `canonicalPair()`. A whole-graph comparison at that late point is invalid as a clean-build oracle because the long-running test has accumulated optimistic and synthetic runtime state. C14 needs an isolated full-versus-patch scenario with equivalent inputs before applying `canonicalGraph()` to both sides.
- The harness no longer transpiles modal modules that it immediately replaces with host stubs. `writeRuntimeStub()` now fails if a stub would overwrite compiled behavior. When an extraction makes a module part of the behavior under test, add it to the transpile list and remove any colliding stub. A passing aggregate test does not establish host independence: C02/C08 must exercise the portable import boundary without an Obsidian shim or fake `window`.

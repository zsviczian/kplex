## Reviewed changes

Predicate AST/dependencies/evaluation, the unchanged parser, and lens include/exclude/style/evidence composition now run under `src/core/plex/`. Production PlexGraph callers delegate to that implementation through legacy compatibility modules. Cached property lookup and plain candidate/evidence mapping live in `src/adapters/obsidian/predicateContracts.ts`. The provider requests one field from live cached Markdown metadata; it does not read bodies or cache arbitrary frontmatter. Evidence is pair-scoped and requested only by evidence lenses. Legacy definition/style sanitation and Simple builders remain for later composition cleanup.

Review fixed several delivered behavior mismatches: raw edge enums retain numeric selector values; descriptive kind/direction remain strings; semantic page mtime is independent of physical file mtime; semantic paths remain available to file/center selectors on unbacked nodes; evidence fallback uses semantic paths rather than requiring file facets. Typed adapters replace unchecked double casts. Idle/null/no-applicable-style paths avoid unnecessary candidate mapping. Existing grammar, expressions, persisted schemas/settings, index/classifier, search, CSS, native gestures and device routing are unchanged.

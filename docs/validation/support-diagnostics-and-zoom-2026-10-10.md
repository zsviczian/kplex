## Privacy, bounds and lifecycle

The support DTO accepts predeclared categories, finite numeric counters, strict version/time grammar, and the maintainer-authorized bounded public metadata: active core/community plugin identities/names/versions and custom theme name. Names preserve Unicode, reject controls/bidi escapes and are not shortened; optional unavailable caches are explicit. Enabled and available CSS snippet counts are reported without names or contents. At most512 plugin rows are retained; omission counts identify list/byte-cap truncation. It excludes vault/node names and paths, note text, custom metadata, URLs, searches, raw settings, account details, tokens, error messages/stacks and arbitrary ASCII reason tokens. Raw console collection is explicitly `unsupported`; detailed existing startup telemetry remains `disabled` unless already opted in. Unknown owners and fields remain unavailable.

The recorder has 96 slots, a 16 KiB event-byte ceiling and 30-minute lazy expiry, without timers, polling, per-file recording or presentation notifications. Output is ≤32 KiB UTF-8, with deterministic oldest-first omission. Clipboard writes begin synchronously before UI creation or await. Actual promise settlement determines copied/failed status; retry uses exactly the displayed bytes. Closing retires the writer/listener lease before native/modal references are released; stale completion cannot update a dismissed report.

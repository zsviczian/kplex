Reuse an image across a guide and release only when it illustrates the same behavior, with an accurate caption. Existing screenshots of older controls remain historical illustrations until their corresponding guide is refreshed. The journal crop is a native capture of the graph region, not a redrawn diagram.

Physical phone/tablet navigation, touch export versus swipe, native Web viewer preferences and on-screen keyboard behavior need actual device captures. A Windows desktop screenshot or emulated narrow viewport must be labeled accordingly and cannot establish physical-device behavior. Do not manufacture a mobile illustration or embed a nonexistent TODO asset in the Help vault.

Before publication, inspect each final image and its rendered Markdown embed, verify asset links, and record actual capture coverage and any remaining gaps in the authoring PR. Agent instructions and this coverage catalog stay in the source repository.
